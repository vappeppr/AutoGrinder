# Changelog

- Release docs, short usage text, new icon.
- Noclip blocks `destroyPlayer` / `playerDestroyed`, not only collisions.
- Page flip no longer waits forever on `pageLoading`.
- Speed uses real wall-clock FPS instead of scaled `dt`.
- After 100% the complete screen stays a few seconds, then the next level starts.
