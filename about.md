# AutoGrinder

Helper for long sessions with online levels.

It walks search pages, lists, dailies, gauntlets and map packs so you spend less time clicking between screens. The loop is fast on purpose. What that means for official stats and other players is your decision.

Unofficial third-party mod. Not affiliated with RobTop, Steam or Geode. Tagged as a cheat on the index because it changes how levels are finished.

## Quick start

1. Install Geode, then this `.geode` file.
2. Launch GD, accept the terms once.
3. Set your own search filters (uncompleted, stars, length — whatever you want).
4. Stay on that screen. Press **F5** for the panel or **F6** to start.
5. **F7** pause, **F8** Geode settings, **F6** again to stop.

Backup `CCGameManager.dat` before a long session. All risk is yours.
